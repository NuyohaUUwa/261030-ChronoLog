# ChronoLog（时光足迹）

面向个人使用的智能知识库、每日足迹与双模日历系统，规划支持 Web 和独立 Android APK。保留注册、登录及多账号数据隔离。

## 当前状态

截至 2026-11-05，项目处于文档与仓库基线阶段：已核验 Windows 开发机和 N100 Linux 的基础环境，应用源码、配置加载器、API、模拟 AI、构建脚本和部署文件尚未实现。以下文档中的工程目录、接口和命令属于实施规范，满足注明的前提后才能执行。

## 设备分工

| 设备 | 职责 | 工具 |
|---|---|---|
| Windows 本机 | 编码、Go／Vite 原生调试、基础测试、APK 打包 | Git、Go、Node.js；Android 工具链待补齐 |
| N100 Linux | Docker 镜像构建、阶段验收、正式运行和数据保存 | 已验证 Docker、Compose、Buildx；SSH：`fun@10.126.126.9` |

Windows 无需 Docker、WSL2 或 Make。日常用浏览器调试，阶段完成后到 N100 验收，涉及原生能力或发布时再打包 APK。开发、验收和正式数据分别存放。
