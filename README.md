# ChronoLog（时光足迹）

面向个人使用的智能知识库、每日足迹与双模日历系统，规划支持 Web 和独立 Android APK。保留注册、登录及多账号数据隔离。

## 当前状态

截至 2026-11-05，项目处于文档与仓库基线阶段：已核验 Windows 开发机和 N100 Linux 的基础环境，应用源码、配置加载器、API、模拟 AI、构建脚本和部署文件尚未实现。以下文档中的工程目录、接口和命令属于实施规范，满足注明的前提后才能执行。

## 设备分工

| 设备 | 职责 | 工具 |
|---|---|---|
| Windows 本机 | 编码、Go／Vite 原生调试、测试、APK 打包与真机验收 | 已有 Git、Go、Node.js、VS Code、Gradle 8.14.3 缓存；JDK 21／SDK 待补齐 |
| 开发侧发布环境 | 构建 linux/amd64 正式镜像 | 本机尚无 Docker，发布前单独补齐；日常开发不依赖它 |
| N100 Linux | 仅正式运行和数据保存 | 历史记录已有 Docker／Compose；每次连接前必须取得用户明确同意 |

Windows 日常开发无需 Docker、WSL2 或 Make。浏览器与 Android 真机都连接本机开发服务，AI 和通知默认模拟；功能验收在本机完成。N100 不承担构建、测试或临时验收。

**N100 连接必须先征得用户对本次目的和范围的明确同意**，包括 SSH、文件传输、HTTP／AI API、只读检查和连通性探测。历史免密连接及已知地址不构成许可；完整规则见 [AGENTS.md](AGENTS.md)。
