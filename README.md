# ChronoLog（时光足迹）

个人记事与双模日历，Go 服务端 + Vue 3 Web，Android 计划采用 Capacitor。保留注册、登录和多账号隔离。

当前推进路线（2026-11-07 用户明确）：
1. **阶段一：服务端功能与接口开发（优先）**：真实 AI 模型接入（DeepSeek/OpenAI）、实用推送渠道扩展（Bark/Webhook）、待办取消 API 及通知深链基础支持。
2. **阶段二：Web 端全量体验与数据可视化**：笔记/标签二次编辑、待办一键完成/取消、多层级标签树导航、时间线与记事热力图、具备可用性的通知直达。
3. **阶段三：安卓移动端开发**：Capacitor 原生深度适配（状态栏与沉浸手势、通知栏推送接收器、离线缓存基础支持）。
