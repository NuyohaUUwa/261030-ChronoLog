## 数据与并发

`DATA_DIR/accounts.db` 保存账号及设置；`DATA_DIR/users/<认证身份映射的邮箱>/notes/*.md` 保存笔记，同用户目录的 `index.db` 是可重建索引。服务端从认证身份推导目录并校验邮箱及笔记 ID，禁止客户端选择路径。

字段以 [markdown.go](../server/internal/storage/markdown.go) 为准：

| 字段 | 约定 |
|---|---|
| id、created_at、updated_at | 服务端生成；时间为带偏移 RFC 3339 |
| raw_content | 独立原稿，保留空白，不从正文反解析 |
| processing_status、failure_reason | processing／ready／failed；失败原因脱敏 |
| revision、current_task_id、user_edited | 修订、异步任务和用户编辑保护 |
| tags、reminders | 标签及结构化提醒 |
| Markdown 正文 | 润色结果，API 对应 polished_content |

提醒含 id、title、remind_at、reason；status 为 pending／completed／cancelled，notification_status 为 pending／sent／failed。发送成功不自动完成待办；当前没有独立取消入口和持久化退避字段。

同笔记写入加锁并原子替换；AI 成功／失败均检查任务 ID，不能复活删除项或覆盖新编辑。更新接口用 updated_at 检查冲突。先保存原稿，再更新索引及处理 AI。启动扫描 Markdown 重建索引并恢复 processing；运行中外部编辑需受控手动重建或重启。异常恢复边界见进度表，不能据此承诺所有失败都能自动修复。

默认 Asia/Shanghai，日历日期为 YYYY-MM-DD。当前按服务配置时区聚合，暂无账号级时区。备份包括笔记、账号数据库、配置及提示词；账号不能由笔记重建。

## 配置契约

依据 [config.go](../server/internal/config/config.go)：非空环境变量 > YAML > 代码默认值。CHRONOLOG_CONFIG 显式指定文件，读取失败即报错。未指定时按 local、普通、example 顺序查找 config/config.local.yaml、config/config.yaml、config/config.example.yaml，每种文件先当前目录、再上级目录。

| YAML 键 | 环境变量 | 代码默认值／约束 |
|---|---|---|
| server.address | HTTP_ADDR | 127.0.0.1:8080 |
| storage.data_dir | DATA_DIR | data-dev |
| app.timezone | APP_TIMEZONE | Asia/Shanghai，须可加载 |
| auth.jwt_secret | JWT_SECRET | 空；启动必填，拒绝占位值 |
| auth.token_expiry_hours | 无 | 720 小时 |
| auth.admin_emails | ADMIN_EMAILS | 默认候选列表见配置示例；环境变量用逗号分隔 |
| auth.admin_setup_key | ADMIN_SETUP_KEY | 空；管理员候选邮箱注册必须匹配 |
| ai.mode | AI_MODE | mock；仅 mock／remote |
| ai.base_url | AI_API_BASE | http://127.0.0.1:3000/v1；remote 要求合法 HTTP(S)，禁止 URL 凭据、查询及 fragment |
| ai.api_key | AI_API_KEY | 空；按上游要求提供，仅存服务端，加载器未强制非空 |
| ai.model | AI_MODEL | 空；remote 必填 |
| ai.timeout_seconds | 无 | 30，必须大于零 |
| notifications.mode | NOTIFICATION_MODE | mock；仅 mock／remote |
| notifications.ntfy_server | 无 | https://ntfy.sh |
| notifications.check_interval_seconds | 无 | 60；非正值由调度器回退为 60 秒 |
| prompts.file | PROMPTS_FILE | config/prompts.local.yaml |

数据与提示词相对路径以工作目录为基准，在 server 中运行时以上级为基准，启动建议传绝对路径。空环境变量不清空 YAML 值。真实配置、密钥、用户数据和签名不入库。

提示词结构以 [prompts.example.yaml](../config/prompts.example.yaml) 为默认模板：system_prompt、dynamic_context_template、few_shot_examples、constraints、model_settings。动态上下文含参考时间、星期、已有标签和原稿，示例使用独立 reference_time。temperature 为 0–2（保留 0），max_tokens 为 1–16000，默认 0.2／1500。管理员修改先校验，再原子替换并热生效。

AI 输出须包含 polished_content、tags、reminders，服务端校验结构、大小和时间，生成提醒 ID 和初始状态。响应上限 1 MiB，不跟随重定向，上游错误脱敏，全服务最多 4 个真实 AI 并发；账号配额尚未实现。mock 回显原稿、空标签／提醒，以 [fail] 开头模拟失败。

## API 索引

以下路径均以 /api/v1 开头，具体请求／响应见对应 handler。除健康及注册／登录外使用 Bearer JWT。错误结构为 `{"error":{"code":"...","message":"..."}}`，常见状态为 400／401／403／404／409／500；跨账号访问笔记返回 404。

| 方法和路径 | 用途／约定 |
|---|---|
| GET /health | 状态、时间及 AI／通知模式 |
| POST /auth/register、/auth/login | email、password；管理员候选注册另需 admin_key；返回 token、身份及模式 |
| GET /auth/me | 当前账号资料 |
| PUT /auth/settings | 非空 ntfy_topic；暂无 Webhook／账号时区 |
| POST /notes | raw_content；原稿保存后返回 202、id、status |
| GET /notes | date、tag、keyword、page、limit；返回 items、total、page、limit |
| GET /notes/:id | 完整笔记，处理中可查询原稿 |
| PUT /notes/:id | polished_content、tags、reminders、updated_at；冲突 409 |
| DELETE /notes/:id | 删除本账号笔记 |
| POST /notes/:id/retry | 重试 AI，processing 拒绝重复启动 |
| POST /notes/:id/reminders/:rem_id/complete | 手动完成待办 |
| GET /calendar/summary | year、month；返回 active_dates、reminder_dates |
| GET /tags | 标签及计数 |
| GET／PUT /prompts | 管理员读取／更新 YAML |
| POST /prompts/test | 管理员以 raw_content 测试 |
| POST /system/rebuild-index | 管理员重建；操作前停止业务写入 |

page 从 1 开始，limit 默认 20、最大 100，组合条件取交集。检索采用 FTS5，短关键词使用 LIKE。前端 baseURL 当前固定为 /api/v1，Android 地址配置待开发。

## 尚未闭环的契约

调度器启动及定时检查用户／通知状态均为 pending 的提醒；成功写 sent，失败写 failed。已有 mock／Ntfy 发送器，但 failed 无自动退避重试，发送后落盘失败仍有重复风险。Webhook、手机送达及通知点击定位尚未验收；点击 URL 当前硬编码，需配置化。

Web 已有响应式布局、快录、卡片、日历、搜索、提示词工具与 DOMPurify 白名单。尚无完整编辑入口。CORS 当前回显请求 Origin，规划中的来源白名单尚未实现，Android 接入前需处理。

修改数据、API 或配置时同步本文、配置示例及开发指南；结果和剩余边界写进度表，原始报告放本机 reviews/。
